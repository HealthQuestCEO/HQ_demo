# HealthQuest Demo Game - Odd One Out

A fun, interactive "Odd One Out" mini-game designed for kids to learn about health topics while having fun!

## Overview

This is a standalone demo game that can be embedded via iframe on landing pages. It features 5 health-themed puzzles where players identify which item doesn't belong in a group.

## Features

- Single HTML file with no external dependencies
- Mobile responsive design
- Iframe-compatible
- Fun health facts after each question
- Score tracking with personalized messages
- Sign-up CTA for the full HealthQuest experience

## How to Play

1. Look at the 4 options presented
2. Click the one that doesn't belong with the others
3. Learn a fun health fact after each answer
4. Complete all 5 questions to see your score!

## Hosting

This game is designed to be hosted on GitHub Pages:

1. Go to repository Settings
2. Navigate to Pages
3. Select "main" branch as the source
4. The game will be available at: `https://[username].github.io/healthquest-demo-game/`

## Embedding

To embed in an iframe:

```html
<iframe
  src="https://[username].github.io/healthquest-demo-game/"
  width="100%"
  height="700"
  frameborder="0"
  style="border-radius: 16px; max-width: 500px;">
</iframe>
```
